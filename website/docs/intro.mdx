hitokoto (一言, "a word") is a tiny language model that hears one short phrase and answers with one short phrase. It aims at simple daily talk, like a pet robot or a smart speaker, and it will run on small devices such as the ESP32 microcontroller or a small FPGA.

hitokoto is still being built. This site will grow with it. See the [roadmap](roadmap.mdx) for what is done and what comes next.

## Goals

### One phrase in, one phrase out

hitokoto will talk in short phrases about everyday things. It will remember the last few turns of the talk, so it can follow what you said a moment ago.

### Runs on tiny devices

The model will have only a few million numbers or less, so it fits in the memory of a microcontroller. The memory it uses for the talk will stay the same size, however long you talk.

### Train it yourself

One GPU will be enough. You will pretrain the model on simple text, teach it daily talk, and get it ready for your device.
