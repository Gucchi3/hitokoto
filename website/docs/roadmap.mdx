| 2 | A small GPT-style model (a few million numbers or less) | <span className="coming-soon">Coming soon</span> |
| 3 | A small tokenizer and pretraining on simple text | <span className="coming-soon">Coming soon</span> |
| 4 | Teaching the model daily talk | <span className="coming-soon">Coming soon</span> |
| 5 | Memory for the talk that stays the same size | <span className="coming-soon">Coming soon</span> |
| 6 | The code around the model on the device (the harness) | <span className="coming-soon">Coming soon</span> |
| 7 | Running on a microcontroller and a small FPGA | <span className="coming-soon">Coming soon</span> |
